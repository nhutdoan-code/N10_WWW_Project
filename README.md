# PhoneNest

Website bán điện thoại và phụ kiện.

## Công nghệ sử dụng

### Backend
- Java
- Spring Boot
- Spring Data JPA
- MariaDB

### Frontend
- React

## Cấu trúc project

- `BE/` - Backend
- `FE/` - Frontend
- `DB/` - Database
- `API_DOCUMENTATION.md` - Tài liệu API
